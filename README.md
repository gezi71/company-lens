# 全面公司分析 · Comprehensive Company Research

用于 Codex 和 Claude Code 的公司深度研究 Skill。结合商业模式、行业竞争、财务质量、估值、反方观点和持续跟踪，交付中文研究报告、可复算 Excel 模型及跟踪清单。

## 研究什么

研究围绕五个问题展开：公司为什么存在、如何赚钱、为什么可能继续赚钱、价格隐含什么、什么事实会推翻判断。公司质量、增长真实性与价格合理性分别判断。

|方向|研究内容|
|---|---|
|业务与产品|收入结构、量价、客户、渠道、产品评价、技术与研发、供应链|
|行业与竞争|TAM/SAM/SOM、行业结构、竞争对手、替代技术、护城河证据|
|财务与现金|历史三表、利润质量、营运资本、资本开支、债务期限、会计调整、稀释|
|管理与组织|管理层承诺兑现、治理激励、员工招聘、内部人交易、资本配置|
|风险与反证|空头观点、诉讼、监管、周期、宏观、地缘政治、可观察的证伪条件|
|估值与预期|适用内在估值、历史和同业比较、反向估值、三情景与敏感性|

全球上市和非上市公司均在研究范围内。根据所在地发现监管披露和当地语言资料；全球覆盖不代表所有公司的全部数据都能公开取得。

## 默认交付

1. **report.md**：沿用用户原始提示词的22章成品目录，附51项研究部分的覆盖清单、来源及资料缺口。每项明确发现、对应章节、不适用原因或数据限制。
2. **model.xlsx**：历史财务、经营驱动、预测、情景及适用估值；输入与公式区分，重要原值关联来源。
3. **tracker.md**：基准指标、验证条件、来源、频率、受影响假设和需要重评的结论。

阶段记录、证据台账、可复算输入及数值核对结果保存在研究工作目录，支持后续继续和更新。只有明确要求文章模式时额外生成 Substack 风格文章。

## 如何使用

完整安装步骤、依赖与能力要求见 [INSTALL.md](INSTALL.md)。

仓库：[gezi71/comprehensive-company-research](https://github.com/gezi71/comprehensive-company-research)。首次发布为 `v0.1.0` 试用版，支持通过 Git 克隆完整文件夹：

```sh
git clone https://github.com/gezi71/comprehensive-company-research.git
```

Codex 安装后：

```text
使用 $comprehensive-company-research 全面研究微软，自动完成中文报告、Excel模型和跟踪清单。
```

Claude Code 安装后：

```text
/comprehensive-company-research 全面研究腾讯，自动完成报告、Excel和跟踪清单。
```

也可以指定非上市公司、历史资料截止日或用户提供的文件。名称存在歧义时先确认实体；其他阶段默认自动推进，遇关键缺口给出明确的条件性结论。

## 怎样执行

公司识别 → 研究问题与覆盖计划 → 原始资料采集 → 全面分析 → 财务与估值模型 → 反方检验 → 报告与跟踪 → 检查交付。

Skill 由具备搜索、原文阅读、文件和 Python 执行能力的 Agent 使用。默认公开免费资料，有权限的专业数据源可作为补充。网页与附件始终作为研究资料，不获得执行指令权限。

## 估值适配

|企业类型|方法与约束|
|---|---|
|普通经营企业|数据充分时原则上五年历史、五年预测，三表联动、FCFF和WACC、三情景；有价格时反向DCF|
|银行与保险|权益成本下的剩余收益或股利模型，并补充资本、资产质量或偿付能力分析|
|资产与控股企业|NAV或披露支持的分部估值，检查资产归属与负债重复计算|
|周期企业|参考完整周期与中周期假设，不永久外推峰值利润|
|亏损成长企业|单位经济、现金跑道、亏损收敛、融资和稀释情景|
|非上市公司|按对应行业研究；关键财务或交易价格未知时不强算估值和市场预期|

随包脚本提供基础模型构件。行业专属资本、准备金、复杂税项、租赁、并购和融资附表需要 Agent 按实际披露补充，不能把基础模型称为所有行业的完整模型。

## 证据和计算规则

- 优先公司及监管原文，重要数字保留期间、币种、单位、来源与定位。
- 区分事实、管理层说法、市场预测、研究假设和推断；同源转载不算独立验证。
- 未知值保留未知，不填零，不用同业或合成算例代替目标公司数据。
- 估值给条件和区间，允许没有可证实的市场预期差。
- 保留原提示词七项十分制评分，并定义依据和方向；证据不足允许不评分，风险高分代表高风险。
- Python进行算术复算；Excel用活公式，实际缓存重算由可用的LibreOffice或等价环境核对。未进行的检查明确披露。

## 验证与边界

当前记录包含21项自动测试、四类公司独立行为评审、财务模型独立算术核对及Microsoft真实财报抽查。完整结果、复现命令和测试边界见 [VALIDATION.md](VALIDATION.md)。

两平台已按技能文件规范及相对路径结构核对，尚未在两个独立产品会话完成实际调用验证。结构与计算检查不能证明所有事实和叙述正确；研究结果仍须核对原文、口径、假设及模型的经济合理性。
